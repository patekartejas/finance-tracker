# ₹ Finance Tracker v12

Google Sheets export update:
- One single CSV export: `finance_tracker_google_sheets.csv`
- Contains expenses, monthly income/resource rows, category, subcategory, fixed/variable type, notes and calculated daily/weekly/monthly allocations and balances.
- Includes a SUMMARY block in the same CSV for easy review/pivoting.
- Designed to import directly into Google Sheets. It is CSV, not an Excel `.xlsx` file.

All previous features remain: automatic income allocation, independent daily/weekly/monthly balances, Parents Care, Child Education, reports, ledger, backup/restore and Android PWA support.

For Android PWA: host the files on HTTPS, open in Chrome, then Add to Home screen / Install app.
